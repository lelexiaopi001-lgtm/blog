# 📖 Aurora 博客部署 · 傻瓜教程（照着点就行）

> 适用：阿里云服务器 + 宝塔面板 + 已有域名
> 全程只需要**鼠标点点点**，不用敲任何命令（除了最后一条复制粘贴）

---

## 第 0 步：登录宝塔面板

打开浏览器，输入你的宝塔地址：

```
http://你的服务器IP:8888
```

输入宝塔账号密码登录。

> ❓ 忘了宝塔地址/密码？
> - 登录阿里云控制台 → 远程连接你的服务器（网页版小黑窗）
> - 输入 `bt` 回车，选 14 查看面板地址，选 5 重置密码

---

## 第 1 步：上传项目文件

1. 宝塔左侧菜单点 **【文件】**
2. 进入目录：`/www/wwwroot`
3. 点右上角 **【上传】** → 选择 `aurora-blog.zip`（就是我给你打包好的那个）
4. 上传完成后，**右键** 这个 zip → 点 **【解压】**（解压到当前目录）
5. 解压后应该看到文件夹：`/www/wwwroot/aurora-blog`

> ✅ 检查：点进去看看，里面应该有 `public` 文件夹、`README.md` 等

---

## 第 2 步：域名解析（让域名指向你的服务器）

1. 打开 **阿里云控制台** → 搜索 **云解析 DNS**
2. 找到你的域名 → 点 **【解析设置】**
3. 点 **【添加记录】**：
   - 记录类型：`A`
   - 主机记录：`@` （或填 `blog`，如果你想用 `blog.你的域名.com` 访问）
   - 记录值：你的**服务器公网 IP**（阿里云控制台 → 云服务器 → 看公网 IP）
4. 保存。等 5~10 分钟生效。

> 💡 想用二级域名（如 blog.xxx.com）就填 `blog`；用主域名（xxx.com）就填 `@`

---

## 第 3 步：创建数据库

1. 宝塔左侧菜单点 **【数据库】** → 点 **【添加数据库】**
2. 填写：
   - 数据库名：`aurora_blog`（或随便，如 `blog`）
   - 用户名：和库名一样，自动生成
   - 密码：点右侧 **【随机】** 生成一个，**复制保存好**（等下要用）
3. 点确定 ✅

---

## 第 4 步：创建网站

1. 宝塔左侧菜单点 **【网站】** → 点 **【添加站点】**
2. 填写：
   - 域名：填你解析的域名（如 `blog.你的域名.com`）
   - 根目录：点右侧的文件夹图标，选择 `/www/wwwroot/aurora-blog/public`  ← **必须选 public 这个文件夹！**
   - PHP 版本：选 **8.0** 或以上（没有 8.x 就选 7.4）
   - 其他都默认
3. 点 **【提交】** ✅

---

## 第 5 步：配置伪静态（重要！）

1. 在 **【网站】** 列表里，找到刚建的网站 → 点 **【设置】**
2. 点 **【伪静态】**
3. 把下面这一行**整段复制**粘贴进去（如果里面本来有内容，先全选删掉）：

```
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

4. 点 **【保存】** ✅

---

## 第 6 步：运行安装向导

浏览器打开：

```
http://你的域名/install.php
```

> （如果用主域名：`http://你的域名/install.php`）
> （如果用二级域名：`http://blog.你的域名.com/install.php`）
> （如果提示文件不存在，可试试 `/tools/install.php`）

1. 页面会显示环境检测，全部是 **绿色 ✓ 通过** 就行
2. 填写：
   - **数据库地址**：`127.0.0.1`
   - **端口**：`3306`
   - **数据库名**：填你第 3 步建的库名
   - **用户名 / 密码**：填第 3 步保存的
   - **站点名称**：填你博客的名字（如"小明的博客"）
   - **管理员用户名 / 密码**：设一个你自己的账号密码（**一定记牢！**）
3. 点 **【开始安装】**
4. 看到 🎉 **安装成功** 就大功告成了！

---

## 第 7 步：收尾（3 件小事）

### ① 删除安装文件（安全！）
1. 宝塔 **【文件】** → 进入 `/www/wwwroot/aurora-blog/public`
2. **右键** `install.php` → **【删除】**
3. 再进入 `/www/wwwroot/aurora-blog/tools`，**右键** `install.php` → **【删除】**（也可直接删掉整个 tools 文件夹）

### ② 配置目录权限
1. 宝塔 **【文件】** → 进入 `/www/wwwroot/aurora-blog/public`
2. 右键 `uploads` 文件夹 → **【权限】** → 全部勾上 → 确定
3. 右键 `/www/wwwroot/aurora-blog/config` → 同样操作

### ③ 开启 HTTPS（免费证书，强烈建议）
1. 宝塔 **【网站】** → 网站 **【设置】** → **【SSL】**
2. 选 **Let's Encrypt** → 勾选你的域名 → 点 **【申请】**
3. 申请成功后，**【强制 HTTPS】** 打开

---

## 🎉 访问你的博客

- 前台：`https://你的域名`
- 后台：`https://你的域名/admin/index.php`（用安装时设的管理员账号登录）

现在你可以去后台写第一篇文章啦！📝

---

## ❓ 出问题了？对照这里

| 现象 | 原因与解决 |
|------|-----------|
| 打不开页面（404/500） | ① 站点根目录是不是选了 `public`？② 伪静态有没有粘贴保存？ |
| 显示"数据库连接失败" | 第 6 步数据库名/用户名/密码填错，回第 3 步核对 |
| 安装向导打不开 | 域名解析还没生效，等 10 分钟；或直接用 `http://服务器IP/install.php`（需先建站） |
| 图片上传失败 | 第 7 步 ② 的 uploads 权限没设置 |
| 后台登录提示令牌错误 | 刷新页面重新登录即可 |
